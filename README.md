# 오후 반차 — 존중시민 (성인)

감정노동 존중 『부천시민다움』 캠페인의 성인용 참여형 웹앱입니다.
반차를 낸 오후 하루 동안 여섯 번의 마주침을 따라가며, 오늘 내가 감정노동자를 대한 방식을 네 가지 유형으로 돌아봅니다.

부천시일쉼지원센터

## 구성

- `index.html` — 단일 파일. 외부 라이브러리·빌드 도구 없음.

## 수정

문안은 `index.html` 위쪽 DATA 블록(`T`, `STEPS`, `ENDING`, `SIGNAL`, `DEF`)에서만 고칩니다. 그 아래 렌더링 코드는 건드리지 않아도 됩니다.

응답 집계를 쓰려면 `COLLECT.url` 에 구글 Apps Script 웹앱 주소를 넣습니다. 비워 두면 아무것도 저장하지 않습니다.

## 출처

「감정노동 존중 신호등 테스트」 문항·등급과 존중시민 슬로건은 『감정노동과 부천시민다움』 자료집 문안입니다.
